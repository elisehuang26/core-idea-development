# 创意推导示例

## 虚构咖啡杯品牌的名字与动作联想

以下为虚构示例，产品名、消费者行为和产品特征均为方法演示的设定。

| 环节 | 推导 |
| --- | --- |
| 观察设定 | 通勤者愿意带自己的咖啡杯，但会在包满时把杯子留在家里。 |
| 洞察假设 | 用户希望保留自带杯的习惯，同时给包里的其他物品留出空间。 |
| 产品设定 | 虚构品牌“折一杯”提供可折叠杯，折叠后的体积变化有对应测试资料。 |
| 主张 | 让自带杯在喝完后占用更少的包内空间。 |
| 联想 | 名字中的“折”也是使用动作。杯子折小后留下的空位，是用户期待的变化。 |
| Core Idea | “折出一个空位”。以折叠动作和新增空位组织创意。 |
| 执行示意 | 通勤者折起喝完的杯子，把刚买的小物放进腾出的空位。 |
| 待验证 | 测试受众能否看懂产品利益，核对真实产品的折叠体积和使用条件。 |

创意跳转发生在“名字与产品动作”以及“用户想腾出空间”之间。两者共同决定了关键画面。

## 爱他美的生活语言与科研联想

这是一个独立的品牌层创意演示。消费者动机为待验证假设，主推 SKU 尚未限定，尚无消费者测试结果。阅读时将公开品牌事实、消费者假设与创意提案分别理解。

### 1. 平台观察

以正在比较配方奶的家庭为对象，查看他们在配料表、产品线区别和适用阶段等问题上如何查资料、做比较和反复核对。

这里的待查行为是“为确认一个选择而反复做功课”。需要用原始笔记、搜索或访谈判断，他们卡在信息难找、术语难懂，还是不同说法互相矛盾。

### 2. 消费者洞察

提出一个待验证假设

> 家长希望自己的选择有依据，也希望关心的那件小事有人认真解释。

将“我的疑问有人回答”作为情绪方向，验证家长是否认可这类回应。

### 3. 产品回应

爱他美公开资料介绍了针对不同产品开展的基础研究与本土临床研究，可从中追溯研究主题和对应产品资料。应用到正式项目时，需要进一步确定主推 SKU 与可以展示的研究依据。[达能中国官方资料](https://www.danone.com.cn/newsroom/press-releases/danone-attends-2025-ciie)

产品在内容里的角色，是把研究和产品设计依据解释给家长听。

### 4. 沟通主张

> 你为孩子认真问过的问题，值得得到认真研究过的回答。

这句话承接家长的认真与品牌的科研，要求每条内容从一个真实问题开始，交付对应答案。

### 5. 创意联想

| 已有素材 | 建立的联系 |
| --- | --- |
| 家长看资料、比较和核对 | 生活里常说的“我研究一下” |
| 爱他美的营养科研 | 专业意义上的“研究” |
| 品牌名字中的“爱他” | 家长做功课的动机 |

“研究”同时形容家长的行动和品牌的工作，“爱他”扣回品牌名字。

### 6. Core Idea 与场景

**爱他这件事，我们一起研究**

用同一个问题连接家庭与科研两个场景。

例如，家长在配料表上圈出“益生元”，提出“它在这款配方里做什么”的问题。内容从圈出的词切到对应研发人员或可展示资料，解释后回到包装，帮助家长理解这一项信息。

这个执行是创作示意，正式制作时使用可追溯的真实问题，以及与主推产品相符的资料。

### 7. 场景验证

| 检验 | 当前判断 |
| --- | --- |
| 消费者关联 | “反复做功课”提供生活画面，需要验证家长最希望获得哪类回答。 |
| 产品关联 | 可以承接科研资产，具体内容需落实到主推产品。 |
| 品牌独占性 | 其他科研品牌也可能使用“研究”的共同语言，需要加入爱他美具体的产品设计和研发细节。 |
| 执行与延展 | 可以从真实提问中形成持续选题，延展成达人提问、研发解读或图文资料。 |

本示例于2026年11月18日整理。使用时核对最新产品资料，并根据目标受众重新验证洞察。
